# Private Owner Approval Protocol

This protocol is mandatory for every AccessRevamp agent, skill, customer
`SKILL.md`, customer `DESIGN.md`, creative version, website preview, poster,
Canva design, cinematic scene, and delivery manifest.

## Before work starts

1. Resolve one exact customer project ID.
2. Verify payment and entitlement when the work is paid.
3. Verify the current customer dossier and exact source-asset manifest.
4. Require the applicable customer `SKILL.md` and `DESIGN.md` to be present,
   source-linked, versioned, and owner-approved in the private owner command center.
5. Stop if any required document is missing, stale, belongs to another project,
   or lacks owner approval.

## Before customer visibility

Register the immutable output version, link exact source evidence, resolve every
critique in a child version, require explicit design approval, then require
separate delivery approval. Reconfirm customer/project identity before any
dashboard publication, email notification, or customer-ready state.

Approval is never inferred from silence, upload success, a prior version,
payment, customer selection, agent judgment, or design approval alone. Only the
owner can approve design and delivery. The command center is local to the
owner's computer and is not part of `accessrevamp.com`.
