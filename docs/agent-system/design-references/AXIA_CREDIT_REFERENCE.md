# Axia Credit Design Reference

Reference reviewed: https://www.axiacredit.com/

Reviewed on: 2026-07-27

Purpose: teach AccessRevamp design agents how to recognize and translate strong
visual communication. This is an inspiration reference, not a reusable template.
Do not copy Axia Credit's copy, branding, logo, imagery, icons, source code,
section composition, or proprietary assets.

## What works

### Immediate visual thesis

The homepage opens with a full-bleed hero image, a dark readability overlay, one
dominant promise, a short supporting line, and one high-contrast action. The
visitor can identify the category, intended outcome, and next action without
reading the rest of the page.

### Controlled visual hierarchy

- The display type is large, condensed, and confident.
- Body copy is quieter and does not compete with the headline.
- Navy provides authority and stability; cyan marks interactive actions.
- White space separates decisions instead of filling every area with decoration.
- Buttons use clear labels and a consistent visual treatment.

### Understandable journey

The experience introduces the offer, gives a reason to continue, explains the
process with a three-step sequence, presents benefits, and closes with a focused
call to action. Alternating light and dark sections create pacing and make the
journey easy to scan.

### Deliberate repetition

The primary action appears at meaningful decision points. Repetition reinforces
the journey without introducing competing actions or changing vocabulary.

## Principles agents may learn

1. Give the hero one job and one dominant promise.
2. Use a real customer-owned focal asset when the source manifest permits it.
3. Keep supporting copy short enough that the composition remains visual.
4. Use contrast to identify the next action, not as decoration.
5. Turn a real ordered customer process into a simple three-step or similarly
   bounded explanation. Do not force numbered steps onto unordered information.
6. Alternate section density or tone to create rhythm.
7. Repeat one primary action only where the visitor has enough context to act.
8. End with a concise decision surface, not another information dump.
9. Make responsive behavior preserve the promise, focal asset, and action order.
10. Give motion one purpose: reveal hierarchy, show progress, or improve spatial
    understanding. Avoid scattered effects.

## Translation requirement

Reference principles must be translated through customer evidence:

| Reference principle | Customer evidence required | Acceptable translation |
|---|---|---|
| Full-bleed hero | Approved focal product, service image, or brand scene | Customer-specific hero composition with its own crop, grid, type, and action |
| One dominant promise | Verified customer phrase, offer, or page goal | A concise approved headline using the customer's language |
| Navy/cyan contrast | Customer palette, market expectations, contrast testing | A different evidence-based palette with an equally clear action hierarchy |
| Three-step explanation | A genuine ordered customer process | The customer's actual process in the correct number of steps |
| Alternating light and dark pacing | Approved palette and content hierarchy | Any customer-specific rhythm that separates decisions clearly |
| Repeated primary CTA | Verified conversion goal | One consistent action repeated only at meaningful decision points |

## Required divergence

Each `DESIGN.md` must state how the concept diverges from this reference in at
least four areas: composition, typography, palette, imagery, motion, section
order, or interaction. The result must be recognizably owned by the customer.

Copied elements rejected:

- Axia Credit wording, claims, brand name, logo, contact details, or button copy.
- Its exact hero composition, image crop, section order, colors, font pairing, or
  decorative shapes.
- Downloaded, traced, regenerated, or visually imitated Axia assets.
- A generic finance-site treatment applied to an unrelated customer.
- Any invented customer claim introduced to make the reference pattern fit.

## Image and concept workflow

Before generating a homepage image, poster, or cinematic scene:

1. Read the customer dossier, approved `SKILL.md`, approved `DESIGN.md`, and
   verified `SOURCE_ASSET_MANIFEST.md`.
2. Select only the reference principles that solve this customer's page goal.
3. Record the customer evidence supporting every selected principle.
4. Define the required divergence before generation.
5. Use exact customer-owned assets for products, logos, packaging, and factual
   brand imagery.
6. Add approved words as editable text; never rely on generated raster text.
7. Submit the immutable version, evidence, translation matrix, and divergence
   statement to the private owner command center.
8. Address critique in a new version. Never overwrite or self-approve.

Passing this reference check does not grant customer visibility. Separate design
approval and customer-delivery approval are still required.
