Lane 02

Worker 6 routing

One reader; two correct send paths.

Every 15 minutes

Read merged Gmail inbox

Worker 6 reads new messages and stores each Gmail message ID exactly once, preventing duplicate routing and duplicate replies.

Classify

Match the thread

Direct mail to support@accessrevamp.shop becomes support. A unique prospect/thread match becomes an owner reply. Ambiguous, legal, privacy, payment, security, abuse, or opt-out mail stops.

Route

Wake only the owner

The assignment includes the complete durable thread, mailbox ID, provider mailbox ID, customer/prospect context, and owning worker code.

Reply

Use the correct sender

Support sends as support@accessrevamp.shop. Prospect replies send through the original Icemail mailbox—not the merged Gmail reader.
